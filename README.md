<img width="390" height="839" alt="image" src="https://github.com/user-attachments/assets/8a860c6d-90d7-483e-b014-a3763574dda9" /># OriScope
Приложение предоставляет:
 - регистрацию и авторизацию пользователей для доступа врачей из одной клиники к данным ее пациентов, а также с разных устройств;
 - возможность автономной работы;
 - хранение и управление данными пациентов;
 - создание и редактирование записей о приемах;
 - ввод данных пародонтологической карты с автоматическим пересчетом необходимых индексов;
 - формирование документа в формате PDF на основе приема и возможность загрузить его на устройство;
 - хранение истории осмотров пациента с визуализацией изменения показателей состояния полости рта;
 - загрузку и хранение изображений, прикрепленных к осмотру.

 ## Стек
 - Kotlin (язык программирования серверной и клиентской частей)
 - Android SDK
 - Jetpack Compose (UI-фреймворк)
 - Spring Boot (фреймворк для разработки серверной части приложения)
 - PostgreSQL (СУБД)
